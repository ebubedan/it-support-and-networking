# My IT Journey: Support, Networking & Systems

A practical learning journal documenting my development in IT support, networking, hardware, software troubleshooting and systems administration.

This repository records tasks I have performed, assisted with, or learned about during my IT experience. Each entry distinguishes hands-on work from observation or classroom learning.

## Areas covered

- **Networking:** wireless access-point troubleshooting, locating room network connections through a switch, IP configuration and network topology.
- **IT support:** software reinstallation, printer setup, Windows troubleshooting and basic diagnostics.
- **Systems:** biometric attendance-system activation and hotel operations software support.
- **Hardware and cabling:** cable crimping, intercom cabling and printer maintenance.
- **Technical exposure:** PBX call diversion, DStv activation and Siemens PLC observation.

## How I document each activity

For each practical task, I aim to record:

1. The situation or problem.
2. My role and the work I carried out.
3. The steps taken, where known.
4. The outcome, without claiming results I did not verify.
5. What I learned and what I would investigate further.
