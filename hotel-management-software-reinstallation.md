# Troubleshooting a Hotel Management Application

## Overview

A manager was unable to use a hotel-management application to register a customer for an available room. I assisted a colleague in addressing the software problem.

## Work carried out

- Went with a colleague to the manager's office.
- Assisted with uninstalling the affected application.
- Reinstalled the application.
- The purpose was to restore the manager's ability to use the software for room registration.

## What I learned

- Reinstalling an application can help resolve certain software problems, although it is not the correct solution for every fault.
- Before reinstalling business software, it is important to consider application data, licences, settings and backups.
- IT support should verify that the application works after installation.

## Further learning

I want to learn how to check application logs, system requirements, database connectivity, permissions and backups before deciding on a repair or reinstallation.
