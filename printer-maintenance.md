# Printer Maintenance and Consumables

## Overview

I gained exposure to checking a desk printer's ink/consumable requirements and identifying the appropriate cartridge or size.

## Learning points

- Printer consumables must match the printer model.
- The model number and cartridge compatibility should be checked before replacing ink.
- Correct installation and a test print help confirm that a replacement is working.

## Further learning

I plan to learn more about paper jams, print queues, driver installation, print quality checks and network printer troubleshooting.
