# Tracing a Room's Network Connection Through a Switch

## Overview

I learned how to locate the network connection serving a room by investigating the relevant network switch.

## What I did / learned

- Took part in troubleshooting to identify the switch connection associated with a room.
- Learned that network switches connect devices within a local area network.
- Gained practical exposure to tracing a network connection from an endpoint back to network equipment.

## Key concepts

- **Switch port:** the physical interface on a switch where a network cable connects.
- **Ethernet link:** the wired connection between network devices.
- **Patch panel:** equipment that helps organise and distribute network cabling.
- **Port identification:** matching a room or endpoint to the correct switch port.
